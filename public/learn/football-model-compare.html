Four Football Models, Scored Fairly

Measured 2026-09-25.

The question

Hank's Tank shows one football model (XGBoost). A shadow margin ridge, ESPN's FPI and the betting market all make the same kind of call. Put them side by side, and score them only on predictions made before kickoff. How do they rank?

Principle 1: only pregame predictions count

Our prediction tables mix real pregame rows with backfills written after the game. The MLB table had 418 of them. The obvious dedupe, "latest row per game", picks exactly the backfilled ones, because a backfill is always the latest write. The comparison therefore takes the latest row among rows written before kickoff. A game whose only row came later is shown greyed out and never scored. For that reason the 2024-25 XGBoost rows, all backfills, are left off the live scoreboard.

Principle 2: compare on the same games

A model that only ran in the easy weeks would look better than it is. The page shows two scoreboards. Head to head counts only the games every model called before kickoff. Full record gives each model all of its own games, but the models are then scored on different games.

Principle 3: a number fetched late can be used for a backtest, not for the record

ESPN keeps FPI's prediction on finished games. Is that number pregame? We checked it against ESPN's own in-game win probability at the first play. Over 602 NFL games the median difference was +0.01 points, and only 0.2% of games differed by more than 3 points. Over 298 FBS games the figures were 0.00 and 1.0%. A number revised after the game would have drifted away from the kickoff value, and these did not. So we trust it for a backtest. We still did not hold it before kickoff, so it goes in a separate box and not on the live scoreboard. From now on, live FPI numbers come from snapshots taken before kickoff.

Why FPI wins early and then ties

By ESPN's own description, FPI uses preseason information: returning starters and recruiting. The ridge only has last season's scores, fading out. In September, preseason priors carry real information. By October, both models have seen the same games, and the rating built from margins alone catches up. The lesson: the cheapest way to improve the ridge is probably a better preseason prior, not more in-season features.

How to defend this

"Aren't you just chasing ESPN?" No. FPI is shown as a reference, like the market. Nothing is tuned toward it. The decision rule is out-of-sample log loss against the market.

"33 NFL games is nothing." Agreed. The page flags any head-to-head below 100 games. The NFL verdict comes from the 569-game backtest, and it is a tie.

"Why is the market converted with a fixed curve in college?" The CFBD feed has spreads but no moneylines. Its σ=15.5 was tuned on 2022, not on the scored games. A fitted value would make the market look slightly better, so the comparison is conservative toward our models.

Confidence and what would raise it

High that the CFB ranking XGB < ridge ≤ FPI < market is real: the intervals clear zero with n=933. Low on any NFL ordering among our models. What would raise it: a full season of live pregame snapshots (FPI, ridge shadow) scored on the page with no backfill in the mix.
